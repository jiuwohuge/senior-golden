## Sprint 分组（每 Sprint ≈ 1 周，可并行前后端）

| Sprint | 范围 | 主要 FP |
|--------|------|---------|
| **S1** | P0 后端写能力 | X-002；A3-001~004；A5-001；A6-001/004；A2-001；A4-001 |
| **S2** | P0 Flutter + 管理端联调 | 同上 FP 的 App UI；审核流端到端；主路径仅远程 API（Mock 层已移除） |
| **S3** | P1 | A5-002~005；A5d-*；A6-002/003；A7-001/003；A4-002~004；A3-005/006 |
| **S4** | P2 + P3 | X-001；A1-003/006/007；A8-005；X-003；A10-001；A9-002/003（DONE） |

**依赖说明**：S2 依赖 S1 契约冻结；S3 依赖 S1 发信与扣邮票稳定；S4 以 **A1-006 → X-001 → A1-007 → X-003 → A10-001** 为推荐顺序（见 `07` §3）。
