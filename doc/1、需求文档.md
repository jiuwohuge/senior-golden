【最终完整版 · 可直接交付开发】
欧美 50+ 全球邮政社交 App 需求文档
一、产品全局定位
- 面向欧美 45+ 人群，纯兴趣陪伴社交
- 无婚恋、无约会、无匹配、无颜值导向
- 全球邮政体系生态：明信片 / 通信名录 / 邮政信箱 / 邮票 / 平邮
- 合规：GDPR、Apple/Google 审核友好
- 风格：成熟、简约、全球感、非小镇、非卡通
--------------------------------------------------------------------------------
二、底部 Tab 结构（固定）
1.Post Wall 明信片墙（原动态）
2.Post Directory 通信名录（原探索）
3.Post Box 邮政信箱（消息）
4.My Post 我的邮政（个人中心）
--------------------------------------------------------------------------------
三、补齐·修正·新增内容（你要求的全部点）
1.所有数值后台可配置（邮票数量、VIP 权益、每日上限等）
2.设备 ID 必采（用于日志、风控、拉黑、防刷）
3.补齐管理后台完整功能
4.修复冲突：加速 = 立即到达，接收方不可再“立即打开”
5.去掉 Like 功能，无闭环、无意义
6.补齐完整注册流程 + 资料完善闭环
--------------------------------------------------------------------------------
四、注册 & 资料完善流程（完整版闭环）
4.1 注册入口
- 邮箱注册（欧美主流）
- 密码设置
- 同意用户协议 & 隐私政策
4.2 年龄强制验证
- 必须选择出生年份
- 最低年龄 45+（后台可配置）
- 低于 45 禁止注册
4.3 基础资料必填
- 昵称
- 国家/地区
- 兴趣标签（至少选 3 个）
- 个人简介（非必填，但鼓励填写）
4.4 头像设置
- 上传照片 / 系统默认头像
- 无性感、无暴露、无违规图
4.5 注册完成
- 自动发放每日邮票（数量后台配置）
- 进入 Tab1：Post Wall 明信片墙
4.6 资料修改入口
- My Post → Edit Profile
- 可修改：昵称、头像、兴趣、简介、国家
- 年龄不可改（防作弊）
--------------------------------------------------------------------------------
五、Tab 1：Post Wall 明信片墙（原动态）
5.1 功能
- 查看全球用户发布的公开明信片
- 发布自己的明信片（文字+图片）
- 评论（仅留言，无点赞）
- 去掉 Like 按钮
5.2 发布规则
- 发布 1 次/天（后台可配置）
- 发布成功 → 奖励 1 枚邮票（后台可开关）
5.3 卡片结构
- 头像 + 姓名 + 年龄 + 国家邮戳样式
- 内容区
- 评论按钮
- ✉️ Send Letter（写信入口）
5.4 评论规则
- 仅文字，无表情包
- 可举报、可删除
- 风控过滤敏感词
--------------------------------------------------------------------------------
六、Tab 2：Post Directory 通信名录（探索）
6.1 呈现形式（你确认的创意）
邮局信件架样式
- 一格 = 一个用户
- 格子内：信封 + 头像 + 姓名 + 国家邮戳
- 点击格子 → 展开用户信息卡
6.2 筛选
- 国家
- 年龄区间
- 兴趣标签
6.3 排序规则
- 同龄优先
- 同兴趣优先
- 无异性优先、无颜值优先
6.4 点击用户卡片
- 查看资料
- 按钮：✉️ Send Letter（写信）
--------------------------------------------------------------------------------
七、Tab 3：Post Box 邮政信箱（核心 · 完整闭环）
7.1 顶部显示
- 普通：Stamps: x/3
- VIP：VIP · Unlimited
7.2 邮差状态提示
- 有平邮在运输中 → 顶部轻提示：A post is on the way
7.3 消息列表
- 挂号信（即时）：标记 ✅
- 平邮（运输中）：标记 ✉️ Delivering…
- 平邮（已送达）：正常显示
--------------------------------------------------------------------------------
八、寄信流程（核心 · 无冲突版）
触发
对方主页 → Send Letter
二选一（所有人可见）
1.Registered Mail（挂号信 · 即时）
- 立即送达
- 消耗 1 枚邮票
- VIP 不消耗
2.Standard Post（平邮 · 慢信）
- 延迟送达（10 分钟～2 小时，后台可配）
- 不消耗邮票
--------------------------------------------------------------------------------
九、平邮（时光邮差）完整闭环（已修复冲突）
9.1 发送方
- 发送后状态：✉️ On the way
- 显示预计到达时间
- 可加速：Speed Up→ 消耗 1 枚邮票
→ 立即送达
→ 状态变为：✅ Delivered
9.2 接收方
- 提示：角标 + 顶部提示 + 列表占位
- 只能等待送达，不能“立即打开”（已解决冲突：加速后直接到达，无需再解锁）
9.3 送达后
- 可查看、可回复
- 回复不消耗邮票
--------------------------------------------------------------------------------
十、Chat Stamp 邮票体系（全部后台可配置）
10.1 可配置项
- 每日登录赠送数量
- 发布明信片奖励数量
- 每日总上限
- 挂号信消耗数量
- 平邮加速消耗数量
- 是否开启奖励开关
10.2 获取规则
- 每日首次登录 → 赠送（后台配置）
- 发布 1 张明信片 → 奖励 1 枚（可关）
10.3 消耗规则
- 发起挂号信 → 消耗 1 枚
- 平邮加速 → 消耗 1 枚
- 回复信件 → 不消耗
- 好友聊天 → 不消耗
10.4 邮票为 0
- 无法发送挂号信
- 只能发送平邮
--------------------------------------------------------------------------------
十一、VIP 会员（全部权益后台可配置）
11.1 可配置项
- 无限邮票（开关）
- 免费加速（开关）
- 无广告（开关）
- 查看访客（开关）
- 无痕访问（开关）
- 推荐权重（开关）
11.2 VIP 核心规则
- 可自由选择：挂号信 / 平邮
- 不会强制即时
- 尊重慢社交需求
