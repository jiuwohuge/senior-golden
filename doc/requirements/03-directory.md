# 模块 3：笔友大厅

需求编号前缀：`DL`

---

## DL-1 整体布局

| # | 规则 |
|---|------|
| DL-1.1 | 底部导航第二个 tab，名称为「笔友」 |
| DL-1.2 | 页面为纵向滚动列表：介绍卡 → 安全提示 → 笔友列表标题 → 笔友卡片列表 |
| DL-1.3 | 可下拉刷新 |
| DL-1.4 | 笔友数据来自后端目录分页接口 `POST /api/directory/users/paging`（60 条／页） |

## DL-2 介绍卡

| # | 规则 |
|---|------|
| DL-2.1 | 页面顶部展示笔友大厅介绍卡 |
| DL-2.2 | 标题：「笔友大厅」 |
| DL-2.3 | 说明文案：「先读资料，再写一封认真来信。这里不做快速匹配。」 |
| DL-2.4 | 介绍卡底部提供「筛选笔友」按钮，点击弹出筛选底 sheet |

## DL-3 安全提示

| # | 规则 |
|---|------|
| DL-3.1 | 介绍卡下方展示安全提示卡片 |
| DL-3.2 | 标题：「先通信，再私聊」|
| DL-3.3 | 文案：「资料只是开始。涉及金钱、投资、验证码、私下联系方式等内容，请等真正熟悉后再决定。」 |
| DL-3.4 | 安全提示永久展示，不可关闭 |

## DL-4 筛选

| # | 规则 |
|---|------|
| DL-4.1 | 筛选底 sheet 包含：国家、年龄范围（45–80）、兴趣标签（多选）、排序方式 |
| DL-4.2 | 排序选项：默认、最新注册、年龄最接近、共同兴趣最多 |
| DL-4.3 | 年龄范围默认 45–80，滑块调节 |
| DL-4.4 | 筛选条件通过 DirectoryFilter 状态管理实时更新列表 |

## DL-5 笔友卡片

| # | 规则 |
|---|------|
| DL-5.1 | 每个笔友展示为全宽卡片，而非缩略网格。设计上强调「阅读资料」，而非「快速刷人」 |
| DL-5.2 | 卡片内容：头像（圆形，58px）+ 昵称 + 性别图标（如有）→ 国家标签 + 年龄标签 → 个人简介（最多 3 行）→ 兴趣标签（最多显示 3 个，超出显示「还有 N 个」）|
| DL-5.3 | 卡片右上角固定显示「先写信」邮票徽章，强调社交起点是信件而非私聊 |
| DL-5.4 | 卡片底部提供「查看资料」按钮，点击后跳转至该笔友的用户资料页 |
| DL-5.5 | 如果该用户还没有写自我介绍，显示默认文案：「这位成员还没有写自我介绍。你可以先看看兴趣，再决定是否写信。」|
| DL-5.6 | 点击整张卡片或在资料页点击「写信」→ 进入统一写信流程（目的地预设为该笔友）|

## DL-6 空状态与错误

| # | 规则 |
|---|------|
| DL-6.1 | 无符合条件的笔友时展示空状态：「没有符合条件的会员」+ 提示「可以清空筛选，或等新的官方主题带来更多来信后再看看」 |
| DL-6.2 | 加载失败时展示错误提示及「重试」按钮 |
