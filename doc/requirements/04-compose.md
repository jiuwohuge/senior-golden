# 模块 4：统一写信流程

需求编号前缀：`CP`

---

## CP-1 入口与路由

| # | 规则 |
|---|------|
| CP-1.1 | 所有写信行为统一进入 `ComposeFlowPage`，不再有独立写信页面 |
| CP-1.2 | 根据传入的 `ComposeIntent`（目的地类型 + 收件人 + 主题键）自动跳转到对应步骤 |
| CP-1.3 | 支持的入口：首页「写一封信」按钮、官方来信「写给未来的自己」、主题卡片「写进这个信箱」、笔友卡片「查看资料」→ 资料页「写信」|
| CP-1.4 | 支持四种目的地类型：`selfTimeLetter`（写给未来的自己）、`penPalMail`（普通笔友信件）、`penPalTimeLetter`（给笔友的时光信）、`topicMailbox`（主题信箱投稿）|

## CP-2 目的地选择（入口页）

| # | 规则 |
|---|------|
| CP-2.1 | 当未指定目的地时，展示三个选项供用户选择 |
| CP-2.2 | 选项一：**「写给未来的自己」**——副标题「给自己写一封时光信，未来某天送达」|
| CP-2.3 | 选项二：**「给一位笔友」**——副标题「写一封普通信件或时光信，寄给已有的笔友」|
| CP-2.4 | 选项三：**「写进主题信箱」**——副标题「分享给社区，你的来信会出现在主题信箱中」|
| CP-2.5 | 每项点击后高亮标记选中状态，底部按钮进入下一步 |

## CP-3 收件人选择

| # | 规则 |
|---|------|
| CP-3.1 | 仅在目的地为「给一位笔友」时出现该步骤 |
| CP-3.2 | 展示已建立笔友关系的用户列表（来自 mailbox friends 接口）|
| CP-3.3 | 列表为空时展示空状态：「还没有笔友」→「去笔友大厅寻找」按钮 |
| CP-3.4 | 列表每行展示笔友昵称 + 国家 |

## CP-4 主题选择

| # | 规则 |
|---|------|
| CP-4.1 | 仅在目的地为「写进主题信箱」且未传入主题键时出现该步骤 |
| CP-4.2 | 展示当前所有可用主题（与首页主题列表一致）|

## CP-5 正文编辑

| # | 规则 |
|---|------|
| CP-5.1 | 提供多行文本输入框，纯文本 |
| CP-5.2 | 字数统计：无下限，上限为 5000 字符，底部实时显示 |
| CP-5.3 | 时光信模式可选内容标签（回忆／感激／日常）和情绪标签（温暖／平静／怀念）, 均为选填 |
| CP-5.4 | 普通信件模式无标签 |

## CP-6 送达日期设置

| # | 规则 |
|---|------|
| CP-6.1 | 仅时光信模式（给自己／给笔友）出现此步骤 |
| CP-6.2 | 日期范围：最短为明天，最长为 3 年内 |
| CP-6.3 | 给自己：最短 7 天后，最长 3 年 |
| CP-6.4 | 给笔友：最短 3 天后，最长 3 年 |
| CP-6.5 | 选择日期后显示人类可读文案：「这封信将在 N 天后送达」|
| CP-6.6 | 时区以设备当前时区为准，送达日 00:00（本地时间）变为可读 |

## CP-7 邮寄选项（普通笔友信件）

| # | 规则 |
|---|------|
| CP-7.1 | 仅普通笔友信出现此步骤 |
| CP-7.2 | 两种选项：平邮（标准，默认）和挂号（需消耗更多邮票，优先处理）|

## CP-8 密封与提交

| # | 规则 |
|---|------|
| CP-8.1 | 密封前展示摘要：目的地、收件人、正文摘要、送达日期（如有时） |
| CP-8.2 | 密封操作：滑动密封滑块完成密封（时光信）或点击提交按钮（普通信件／主题投稿）|
| CP-8.3 | 密封后时光信进入在途状态；普通信件进入投递流程；主题投稿作为明信片内容发布 |
| CP-8.4 | 密封时光信消耗 1 张邮票；余额不足时跳转到充值入口 |
| CP-8.5 | 密封后 24 小时内可在在途列表中取消（仅时光信）|
