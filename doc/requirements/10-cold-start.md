# 模块 10：冷启动与种子数据

需求编号前缀：`CS`

---

## CS-1 官方账号与小助手

| # | 规则 |
|---|------|
| CS-1.1 | 系统维护一个官方账号「时光邮局」，不伪装成真实用户 |
| CS-1.2 | 每日自动生成一封官方来信推送到所有用户的首页 |
| CS-1.3 | 官方来信内容由程序生成（可对接 AI 文案），主题与当日话题一致 |
| CS-1.4 | 官方账号不可被搜索、不可被加为笔友、不可被拉黑 |

## CS-2 定时种子数据

| # | 规则 |
|---|------|
| CS-2.1 | 冷启动初期（用户量 < 预设阈值），系统每天定时生成若干笔友账号和信件数据 |
| CS-2.2 | 种子笔友账号标记为「种子用户」，不在笔友列表中向其他种子用户展示 |
| CS-2.3 | 种子数据包含：笔友资料（昵称、国家、年龄、兴趣、简介）和往来信件 |
| CS-2.4 | 种子数据的生成逻辑由后端脚本或定时任务执行 |
| CS-2.5 | 当真实活跃用户达到阈值后逐步减少种子数据比例至完全关闭 |

## CS-3 官方小助手

| # | 规则 |
|---|------|
| CS-3.1 | 「时光邮局小助手」以官方笔友身份出现在笔友列表中 |
| CS-3.2 | 小助手可接收普通用户信件，并自动回复（可对接 AI 生成回复）|
| CS-3.3 | 小助手回复速度：最长 24 小时内 |
| CS-3.4 | 小助手明确标注为「官方小助手 · AI 辅助回复」|
