# 模块 11：付费与盈利

需求编号前缀：`PM`

---

## PM-1 VIP 会员

| # | 规则 |
|---|------|
| PM-1.1 | 按月 / 年订阅 |
| PM-1.2 | 权益：(1) 挂号信无限量发送 (2) 平邮 2 小时优先处理 (3) 每日免费加速 1 封 |
| PM-1.3 | 付费入口在会员中心页 |

## PM-2 纪念册 Pro

| # | 规则 |
|---|------|
| PM-2.1 | 付费解锁纪念册高级功能 |
| PM-2.2 | 权益：(1) 不限量收藏 (2) 高级排版主题 (3) 导出为 PDF／打印实体册页 |
| PM-2.3 | 该功能为二期规划，MVP 暂不实现 |

## PM-3 邮票

| # | 规则 |
|---|------|
| PM-3.1 | 每日系统赠送邮票：非会员 1 张 / 天，VIP 2 张 / 天 |
| PM-3.2 | 邮票可购买（定价参考：1 元 / 张，批量购买打折）|
| PM-3.3 | 时光信密封消耗 1 张；挂号信额外消耗 1 张；平邮不消耗 |
| PM-3.4 | 余额不足时提示用户前往充值，不阻塞写信体验 |

## PM-4 纪念邮票 / 信纸（二期）

| # | 规则 |
|---|------|
| PM-4.1 | 可购买的虚拟邮票和信纸主题，用于装饰时光信 |
| PM-4.2 | 邮票在阅读和纪念册中展示 |
| PM-4.3 | 信纸影响写信编辑器的视觉风格 |
