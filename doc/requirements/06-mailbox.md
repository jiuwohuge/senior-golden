# 模块 6：信箱（收件箱 / 笔友对话）

需求编号前缀：`MB`

---

## MB-1 整体布局

| # | 规则 |
|---|------|
| MB-1.1 | 底部导航第三个 tab，名称为「我的信箱」|
| MB-1.2 | 顶部展示邮票余额徽章（当前余额 / 日上限），VIP 用户额外展示 VIP 标识 |
| MB-1.3 | 顶部右侧「归档」按钮 → 已归档信件列表 |
| MB-1.4 | 三个 tab 页签：收件箱 / 笔友 / 时光信 |

## MB-2 收件箱

| # | 规则 |
|---|------|
| MB-2.1 | 展示所有收到的邮政信件（普通 + 挂号）|
| MB-2.2 | 每条卡片展示：笔友头像 + 昵称 → 信件预览（最多 2 行）→ 送达时间 → 信件状态标签（运送中／已送达／挂号）|
| MB-2.3 | 信件按送达时间倒序排列 |
| MB-2.4 | 点击进入信件详情页：正文全文 + 笔友信息 + 时间线 |
| MB-2.5 | 详情页底部提供回复按钮 → 进入统一写信流程（目的地预设为该笔友）|
| MB-2.6 | 收件箱支持下拉刷新 |

## MB-3 笔友视角的 IM（即时聊天）

| # | 规则 |
|---|------|
| MB-3.1 | 「笔友」子 tab 展示所有已建立通信关系的笔友列表 |
| MB-3.2 | 每条展示：笔友头像 + 昵称 + 最后一条消息预览 + 时间 + 未读红点 |
| MB-3.3 | 点击进入聊天页，使用腾讯云 IM SDK 实现实时消息传递 |
| MB-3.4 | 聊天页仅在双方已建立笔友关系后可用 |
| MB-3.5 | 聊天页顶部展示笔友昵称和头像，底部为输入框 + 发送按钮（带老年人友好大号 emoji 面板）|
| MB-3.6 | 未读数通过 IM SDK 会话回调实时同步，底部导航「我的信箱」tab 展示未读红点 |
| MB-3.7 | 点击某一笔友进入聊天后清除该笔友的未读标记 |

## MB-4 写信选项

| # | 规则 |
|---|------|
| MB-4.1 | 收件箱列表和笔友列表均支持「写信」入口 |
| MB-4.2 | 收件箱：信件详情页底部「回复」→ 统一写信流程 |
| MB-4.3 | 笔友列表：点击聊天页顶部菜单或资料页「写信」→ 统一写信流程 |

## MB-5 归档

| # | 规则 |
|---|------|
| MB-5.1 | 归档列表展示所有被归档的信件（手动归档或自动归档）|
| MB-5.2 | 归档列表结构与收件箱一致 |
