# 模块 1：注册与登录

需求编号前缀：`AU`

---

## AU-1 欢迎页

| # | 规则 |
|---|------|
| AU-1.1 | 未登录用户打开 App 时进入欢迎页 |
| AU-1.2 | 欢迎页展示 App 名称「时光邮局」、品牌短句「可信笔友，慢慢来信」 |
| AU-1.3 | 展示三个核心卖点：(1) 以从容节奏写信收信 (2) 在全球名录结识笔友 (3) 为 45 岁以上成年人设计 |
| AU-1.4 | 页面底部两个主按钮：「创建账号」→ 注册流程；「登录」→ 登录页 |
| AU-1.5 | 页面底部展示《用户协议》和《隐私政策》链接，首次注册时必须同意 |
| AU-1.6 | 已登录用户（JWT 未过期）跳过欢迎页，直接进入首页（主题信箱） |
| AU-1.7 | 登录态过期（JWT 过期）时清除 token 并跳转回欢迎页 |
| AU-1.8 | 后端 API 返回 401 时尝试刷新 token；刷新失败则清除 token 跳转回欢迎页 |

## AU-2 邮箱密码注册

| # | 规则 |
|---|------|
| AU-2.1 | 注册为分步向导形式，共 7 步：昵称、性别、出生年份、国家/地区、兴趣标签（≥3）、头像（选填）、确认提交 |
| AU-2.2 | **昵称**：必填，1–20 字符，不可全为空格，不含 emoji，支持中文／英文／数字／常见符号 |
| AU-2.3 | **昵称唯一性**：提交时由后端校验；若已存在提示「该昵称已被使用」 |
| AU-2.4 | **性别**：选填，三选一（男／女／保密），默认为空 |
| AU-2.5 | **出生年份**：必填，范围 = `当前年份 - 后端 minRegisterAge` 到 `当前年份 - 110`。用户通过滚动选择器选取 |
| AU-2.6 | **国家／地区**：根据设备语言自动推荐默认国家（zh → CN，en → US 等）；用户可在下拉列表中修改 |
| AU-2.7 | **兴趣标签**：必选 ≥ 3 个；标签列表由后端 `/api/bootstrap` 接口返回 |
| AU-2.8 | **头像**：选填，可从相册选取并裁剪为正方形后上传 OSS；不上传则使用默认头像（昵称首字圆形） |
| AU-2.9 | 最后一步展示全部填写信息的摘要卡，用户确认后提交 |
| AU-2.10 | 提交字段：email、password、nickname、gender、birthYear、countryCode、interestTagIds（≥3）、avatarUrl（可选）、agreedTerms |
| AU-2.11 | 邮箱实时校验：输入框失焦后调用 `POST /api/auth/register/email-check`；若已占用则提示「该邮箱已注册」 |
| AU-2.12 | 邮箱格式校验：符合标准 email 格式，自动转为小写 |
| AU-2.13 | 密码规则：至少 8 位，含字母和数字 |
| AU-2.14 | 注册成功：自动登录并保存 JWT token，跳转到首页 |
| AU-2.15 | 注册失败：显示后端返回的具体错误（邮箱已注册、昵称已占用、服务异常等） |

## AU-3 Google 第三方登录

| # | 规则 |
|---|------|
| AU-3.1 | 登录页展示「Google 登录」按钮；仅在 Android 平台显示 |
| AU-3.2 | 调用 Google Sign-In SDK 获取 idToken |
| AU-3.3 | 后端验证 idToken：已注册用户→直接登录；新用户→返回基本资料（邮箱、昵称）进入补充资料页 |
| AU-3.4 | 补充资料页填写：昵称、性别、出生年份、兴趣标签（≥3）、头像（与注册规则一致） |
| AU-3.5 | 补充资料提交后注册完成，自动登录 |
| AU-3.6 | Google SDK 调用失败时提示「Google 登录暂不可用」 |

## AU-4 邮箱密码登录

| # | 规则 |
|---|------|
| AU-4.1 | 输入邮箱 + 密码，点击登录 |
| AU-4.2 | 登录成功：保存 JWT token 和用户 session，跳转至首页 |
| AU-4.3 | 登录失败：显示后端返回的错误（邮箱不存在、密码错误、账号已停用等） |
| AU-4.4 | 登录页底部「忘记密码？」链接跳转至忘记密码流程 |

## AU-5 忘记密码

| # | 规则 |
|---|------|
| AU-5.1 | 两步流程：(1) 输入邮箱→点击发送验证码 (2) 输入验证码 + 新密码→重置 |
| AU-5.2 | 后端检查邮箱是否存在，不存在则提示「该邮箱未注册」 |
| AU-5.3 | 新密码规则与注册一致：≥ 8 位，含字母和数字 |
| AU-5.4 | 重置成功后提示「密码已重置」并跳转至登录页 |

## AU-6 登出

| # | 规则 |
|---|------|
| AU-6.1 | 入口：「我」tab → 设置 → 退出登录 |
| AU-6.2 | 点击后弹出确认弹窗「确定退出登录？」 |
| AU-6.3 | 确认后清除本地 JWT token 和 session，跳转至欢迎页 |

## AU-7 登录态管理

| # | 规则 |
|---|------|
| AU-7.1 | JWT token 保存在 flutter_secure_storage 中，App 重启后自动恢复 |
| AU-7.2 | App 从后台切回时检查 JWT 是否过期；过期则清除 token 跳转至欢迎页 |
| AU-7.3 | 后端 API 返回 401 时触发 token 刷新；刷新失败则清除 token 跳转至欢迎页 |
| AU-7.4 | AppSessionState 包含：用户资料、邮票余额、日邮票上限、VIP 状态 |

## AU-8 儿童保护与合规

| # | 规则 |
|---|------|
| AU-8.1 | 注册年龄下限为 45 岁（后端 `minRegisterAge` 配置，默认 45） |
| AU-8.2 | 头像经后端机器审核，状态：通过／待审核／驳回。驳回时不展示，直至用户重新上传 |
