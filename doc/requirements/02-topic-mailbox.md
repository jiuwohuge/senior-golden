# 模块 2：主题信箱（首屏）

需求编号前缀：`TM`

---

## TM-1 整体布局

| # | 规则 |
|---|------|
| TM-1.1 | 打开 App 后首页为首个 tab「主题信箱」，作为整个应用的入口和导航锚点 |
| TM-1.2 | 页面结构从上到下：邮件戳装饰条 → 今日信箱面板 → 官方来信卡片 → 每日主题列表 → 安全提醒 |
| TM-1.3 | 整页为纵向滚动列表，可下拉刷新 |
| TM-1.4 | 所有文本字号遵循「老年友好」标准：正文 ≥ 16sp，标题 ≥ 20sp |

## TM-2 今日信箱面板

| # | 规则 |
|---|------|
| TM-2.1 | 面板顶部展示用户昵称问候语：「{昵称}，今天慢慢来」（昵称为空时显示「朋友，今天慢慢来」） |
| TM-2.2 | 简介文案：「这里不催促。可以读一封来信，写一封认真回信，或从今日主题开始。」 |
| TM-2.3 | 展示待处理来信数：来自普通邮政信件的未读数量 |
| TM-2.4 | 展示时光信概览：「在途 N · 可拆 M」——在途指已密封未送达的信件数，可拆指已送达未阅读的信件数 |
| TM-2.5 | 底部两个按钮：「写一封信」→ 统一写信流程；「打开信箱」→ 跳转至「我的信箱」tab |
| TM-2.6 | 数据加载中时显示「加载中 / Checking」占位；加载失败时不阻塞页面，仅显示「—」|

## TM-3 官方来信卡片

| # | 规则 |
|---|------|
| TM-3.1 | 官方来信由系统每天生成，内容偏向温和引导（如「今天可以写一段回忆、一顿饭，或一个你仍然想念的地方」） |
| TM-3.2 | 卡片强制标注「官方来信 · 明确标注」，不允许伪装成真实笔友 |
| TM-3.3 | 卡片底部提供行为按钮：「写给未来的自己」→ 进入时光信写信流程（目的地预设为「给自己」） |
| TM-3.4 | 官方来信仅有一条，显示在今日信箱和每日主题之间 |

## TM-4 每日主题信箱

| # | 规则 |
|---|------|
| TM-4.1 | 展示当日可写的主题列表。目前预设三个主题（后续可由后台配置增减） |
| TM-4.2 | 预设主题：(1)「记忆里的故乡」— 写一条路、一个集市、一扇门 (2)「退休后的安静一天」— 写一个舒服的普通时刻 (3)「老照片背后的故事」— 从一张老照片里选一个元素写下来 |
| TM-4.3 | 每个主题卡片可点击进入统一写信流程（目的地预设为该主题信箱） |
| TM-4.4 | 顶部说明文字：「选一个温和的话题慢慢写。好信件比长时间刷屏更重要。」 |

## TM-5 安全提醒

| # | 规则 |
|---|------|
| TM-5.1 | 页面底部展示安全提醒卡片 |
| TM-5.2 | 文案：「涉及金钱、投资、验证码、私下联系方式等内容会被谨慎提醒。你可以慢慢写，也可以慢慢决定。」 |
| TM-5.3 | 安全提醒永久展示在首页底部，不可关闭 |
