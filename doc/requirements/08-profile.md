需求编号前缀：`PR`

---

## PR-1 个人资料卡片

| # | 规则 |
|---|------|
| PR-1.1 | 展示用户头像（圆形，80px，审核状态标签叠加在上方）|
| PR-1.2 | 头像审核状态标签：「审核中」黄色徽章 / 「已驳回」红色徽章。驳回时头像显示为灰色禁止图标 |
| PR-1.3 | 展示昵称 + 国家徽章 + 个人简介 |

## PR-2 邮票余额

| # | 规则 |
|---|------|

| PR-2.2 | 邮票余额在「我的」和信箱顶部均有显示 |

## PR-3 菜单列表

| # | 规则 |
|---|------|
| PR-3.1 | 菜单项按顺序：编辑资料 / 我的明信片 / 兴趣标签 / 邮票流水 / 黑名单 / 意见反馈 / 设置 / 用户协议 / 隐私政策 |
| PR-3.2 | 编辑资料：修改昵称、个人简介、头像、出生日期；国家不可修改 |
| PR-3.3 | 兴趣标签：管理已选兴趣 |
| PR-3.4 | 邮票流水：查看邮票增减明细（时间、操作说明、变动数、余额）|
| PR-3.5 | 黑名单：查看已拉黑的用户列表，可取消拉黑 |
| PR-3.6 | 意见反馈：提交文字反馈到后端 |
| PR-3.7 | 设置：语言切换（中文 / English）、深色模式开关、关于页面 |
