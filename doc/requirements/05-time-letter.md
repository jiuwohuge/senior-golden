# 模块 5：时光信

需求编号前缀：`TL`

---

## TL-1 在途列表

| # | 规则 |
|---|------|
| TL-1.1 | 入口：「我的信箱」tab → 时光信 tab |
| TL-1.2 | 列表展示所有已密封未送达的时光信 |
| TL-1.3 | 每条卡片展示：收件人（自己昵称 / 笔友昵称）、送达倒计时（「还有 N 天送达」）、密封时间 |
| TL-1.4 | 正文完全隐藏，不可预览 |
| TL-1.5 | 按送达日期升序排列（最先到期的在上方）|
| TL-1.6 | 密封后 24 小时内显示「取消密封」按钮，点击后退回草稿状态；超过 24 小时取消按钮消失 |
| TL-1.7 | 在途信件可提前收藏至纪念册，收藏不影响送达状态 |

## TL-2 送达与阅读

| # | 规则 |
|---|------|
| TL-2.1 | 到达指定日期后，在收件人视角标记为「可拆」（unread）|
| TL-2.2 | 首页今日信箱面板同步更新在途 / 可拆统计 |
| TL-2.3 | 第一次打开信件时展示视觉开信动画（信封撕裂效果）|
| TL-2.4 | 阅读页展示：正文全文、寄件人昵称、收件人、送达日期、情绪标签 |
| TL-2.5 | 阅读后可收藏至纪念册，收藏后该信在原列表消失 |
| TL-2.6 | 阅读后状态变为「已读」，不再出现在可拆列表 |

## TL-3 草稿

| # | 规则 |
|---|------|
| TL-3.1 | 草稿保存在本地（手动保存 / 切换后台自动保存）|
| TL-3.2 | 草稿支持所有字段的保存与恢复：正文、收件人、送达日期、标签 |

## TL-4 取消密封与退款

| # | 规则 |
|---|------|
| TL-4.1 | 密封后 24 小时内可取消 |
| TL-4.2 | 取消后信件回到草稿状态，所有字段保留可编辑 |
| TL-4.3 | 若已被对方拉黑，未送达的时光信自动取消并退回邮票 |

## TL-5 反滥用

| # | 规则 |
|---|------|
| TL-5.1 | 单日发送数量上限：非会员 3 封，会员 10 封 |
| TL-5.2 | 系统不推送信件正文，仅推送「您有一封时光信已送达」|
