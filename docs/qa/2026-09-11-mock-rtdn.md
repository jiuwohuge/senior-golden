## 缺陷

### BUG-RTDN-1 · P1 · mock-rtdn 写 webhook 失败
- **现象**：`POST /api/billing/mock-rtdn` 业务 code=400；`success=false`
- **根因证据**（响应 message）：`bu_payment_webhook_event.payload_json` 列类型 `jsonb`，MyBatis insert 以 `character varying` 写入，缺 jsonb TypeHandler / cast
- **影响**：RTDN Mock 回放整条链路不可测；CANCEL/EXPIRE/REFUND/RENEW + 幂等均 BLOCKED
- **建议**：对齐此前 `log_admin_operation.details` 修法（`PostgresJsonbTypeHandler` 或 `::jsonb`）

## 结论
**未通过**：绑定 PURCHASED OK；RTDN 回放 0/4 场景 + 幂等未测通；**1 个 P1**（webhook `payload_json` jsonb 类型）。阻塞提测闭环，需开发修后回归。
