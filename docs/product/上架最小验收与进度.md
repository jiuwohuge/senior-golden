# 上架最小验收与进度

> **版本**：v0.1 · **更新**：2026-09-10 · **基线分支**：`master`  
> **真源优先级**：本文件 > [`改版整改落地计划.md`](改版整改落地计划.md) > [`../decisions/改版方向讨论稿.md`](../decisions/改版方向讨论稿.md)  
> **对齐**：[付费计划与竞品借鉴.md](./付费计划与竞品借鉴.md) · 产品「上架最小验收」v0.1 + 测试检查表；变现以 **Google Play App 订阅为主，AI=订阅权益**。

## 0. 范围

- 目标：能上 Google Play 的最小闭环（愿意写 / 愿意等 / 可订阅），不是 5.0 全量一次做完。
- 工程基线：`master`（原 4.0 可跑形态合入后）。
- 5.0 未落地项只验「已实现部分 + 订阅」；未做的标缺口，不挡环境自检。

## 1. 核心链路（必须过）

1. 冷启动可进主界面（静默或现有登录墙以当前包为准，记实际路径）
2. 写信 → 封缄/寄出 → 在途可见 → 到达可拆封读信（时光信或邮局至少一条通）
3. 回信 / 信箱列表可读；空态与错误提示可读
4. 拉黑/举报入口可达；无 IM
5. 海外向：关键文案英/本地化不崩

## 2. 订阅权益矩阵（验收口径）

| 状态 | 期望 |
| --- | --- |
| 未订阅 | 可完成核心写信/等信；订阅入口可见；高级 AI 不可用或明显限次 |
| 订阅中 | Play 购买成功后权益立即生效（高级 AI 等订阅权益开） |
| 恢复购买 | 重装/换机后 Restore 能拉回权益 |
| 过期/取消 | 权益收回；核心写信仍可用，不锁死主路径 |
| 断网/杀进程 | 本地缓存与下次校验后状态一致，不乱发权益 |

付费原则：卖订阅，不卖匹配公平；旧商店皮肤不作主商业。

## 4. 与测试清单对齐

- 拿包：全栈推 `master`（或约定分支）后的可安装包 + versionCode/Name
- 订阅：Billing 拉起/购买/恢复/取消 + §2 状态表（**当前 Blocker：Billing 未接**）
- 上架前：崩溃/ANR、权限时机、适老可读、商店文案与应用内一致

## 5. 已知缺口

- 完整 Play Billing + 服务端校验/对账 → **Blocker**（上架订阅闭环）
- 订阅权益矩阵落地（高级 AI 闸）→ P0
- Flyway 上线前整理 → 发布窗口项
- 静默进默认策略真机确认 → P1
