# 上架最小验收与进度

> **版本**：v0.2 · **更新**：2026-09-10 · **基线分支**：`feat/play-billing-v1`（合入后跟 `master`）  
> **真源优先级**：本文件 > [`改版整改落地计划.md`](改版整改落地计划.md) > [`../decisions/改版方向讨论稿.md`](../decisions/改版方向讨论稿.md)  
> **对齐**：[付费计划与竞品借鉴.md](./付费计划与竞品借鉴.md) · 产品「上架最小验收」；变现以 **Google Play App 订阅为主**；权益 = **AI 周配额 + 在途短窗撤回/改信**。

## 0. 范围

- 目标：能上 Google Play 的最小闭环（愿意写 / 愿意等 / 可订阅），不是 5.0 全量一次做完。
- 工程基线：`master`（原 4.0 可跑形态合入后）。
- 5.0 未落地项只验「已实现部分 + 订阅」；未做的标缺口，不挡环境自检。

## 1. 核心链路（必须过）

1. 冷启动可进主界面（静默或现有登录墙以当前包为准，记实际路径）
2. 写信 → 封缄/寄出 → 在途可见 → 到达可拆封读信（时光信或邮局至少一条通）
3. 回信 / 信箱列表可读；空态与错误提示可读
4. 拉黑/举报入口可达；无 IM
5. 海外向：关键文案英/本地化不崩

## 2. 订阅权益矩阵（验收口径）

| 状态 | 期望 |
| --- | --- |
| 未订阅 (none) | 可完成核心写信/等信；订阅入口可见；AI 润色+灵感合计约 **3 次/周**（可配）；在途撤回/改信不可用（升级提示） |
| 试用中 (trial) | 年订试用期内与订阅中同权：AI 高配额 + 在途短窗撤回/改信 |
| 订阅中 (active) | Play 购买成功后权益立即生效（AI 高配额 + 寄出后约 15–30 分钟在途撤回/改信，默认 20 分钟） |
| 恢复购买 (restore) | 重装/换机后 Restore 能拉回权益 |
| 过期/取消 (expired) | 收回 AI 高配额与在途撤回；核心写信/寄出/阅读仍可用，**不锁**主路径 |
| 断网/杀进程 | 本地缓存与下次服务端校验后状态一致，不乱发权益 |
| 在途短时撤回/可改 | 未订：不可撤回（或仅升级提示）；订阅/试用：寄出后窗口内（15～30 分钟）可改/撤回；超时不可；过期收回该权益 |

**在途撤回/改信专项**

| 场景 | 期望 |
| --- | --- |
| 订阅中 + 本人发出 + 仍在途 + 窗内 | 可改正文 / 可撤回为草稿（或取消在途） |
| 订阅中 + 窗外或已送达 | 操作拒绝，提示窗口已过 |
| 未订阅 | 入口仅升级提示，不可改不可撤 |
| Web / 本地无 Play | 可用服务端 `test-override` 模拟 trial/active/expired，跑闸测 |

付费原则：卖订阅（AI + 短窗纠错），不卖匹配公平；旧商店皮肤 / PDF / 邮戳店不作本轮主商业；对接 **Play Billing**（真机）+ Web 可测 harness。
