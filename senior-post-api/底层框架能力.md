# Senior Post 项目框架使用指南

## 文档目的

本文档旨在帮助 AI 或开发者在 **senior-post** 项目中正确使用框架提供的公共组件，避免重复造轮子。所有框架能力均来自 `commons-*` 模块。

---

## 一、框架能力总览

### 1.1 可用模块

| 模块 | 提供的功能 |
|------|-----------|
| **commons-basic** | 请求上下文、Token解析、异常定义、工具类 |
| **commons-data** | 领域模型基类、DTO基类、分页组件 |
| **commons-web** | 统一响应封装、Token认证过滤器、异常处理 |
| **commons-security** | AES数据加解密（APP接口安全） |
| **commons-feign-bridge** | 跨服务调用CRUD接口、代码生成模板 |
| **commons-redis-starter** | Redis操作模板（自动配置） |

### 1.2 API 路径与安全约定（App / 管理端）

| 前缀 | 用途 | 统一响应 / `85xx` | AES 加解密（commons-security） |
|------|------|-------------------|--------------------------------|
| **`/api/**`** | 移动端 App | 是 | 可按环境对请求解密、响应加密（与 `jh.security` 中 `resEncryptUris` / `reqDecryptUris` 对齐）；**收尾阶段再在客户端统一封装** |
| **`/webapi/**`** | 管理后台（对内） | 是 | **不做**加解密，须在 `resIgnoreEncryptUris` / `reqIgnoreDecryptUris` 中排除（与 `/webapp/**` 同类） |

框架拦截与 JSON 包装：`jh.config.interceptor-pattern`、`converter-json-pattern` 需**同时包含** `/api/**` 与 `/webapi/**`。

常量：`AppServiceDefine.SERVER_PREFIX`（`/api`）、`AppServiceDefine.WEBAPI_PREFIX`（`/webapi`）。管理端 Controller 契约建议放在 `client` 模块并统一 `@RequestMapping(WEBAPI_PREFIX + "/...")`。

### 1.3 数据库迁移（Flyway）

- 脚本目录：`server/src/main/resources/db/migration`，命名 `V{version}__{description}.sql`。
- 启动时随 Spring Boot 自动迁移；本地需配置可用的 `spring.datasource`（如 `application-local.yml`）。
- **表结构以 Flyway 脚本为唯一可信源**；具体域表规划见 `PLAN.md`「库表规划」。

## 二、请求上下文 (MyRequestContextHolder)

### 2.1 为什么要用

在 Controller/Service 中获取当前请求的用户信息、IP地址、客户端版本等，必须通过上下文获取，不能自行从 HttpServletRequest 解析。

### 2.2 核心方法速查

```java
// 获取当前请求上下文（包含所有信息）
RequestContext context = MyRequestContextHolder.getContext();

// ====== 用户信息 ======

// 获取当前用户ID（返回 String）
String userId = MyRequestContextHolder.userId();

// 获取当前用户ID（返回 Long，转换失败返回 null）
Long userIdNum = MyRequestContextHolder.userIdNum();

// 获取完整的 TokenInfo 对象
TokenInfo tokenInfo = context.getTokenInfo();

// ====== 客户端信息 ======

// 获取客户端版本号（如：101, 102）
Long version = MyRequestContextHolder.version();

// 获取客户端类型（如：Android, iOS）
String clientType = MyRequestContextHolder.clientType();

// 获取设备ID
String deviceId = MyRequestContextHolder.equipmentId();

// ====== 请求来源 ======

// 获取真实IP地址（自动处理代理）
String ip = MyRequestContextHolder.ipAddress();

// 获取国家
String country = MyRequestContextHolder.country();

// 获取设备归属地
String attribution = MyRequestContextHolder.attribution();

// ====== 请求追踪 ======

// 获取 TraceId（用于日志追踪）
String traceId = context.getTraceId();

// ====== 请求原始数据 ======

// 获取请求体（JSON字符串）
String body = context.getBody();

// 获取请求头Map
Map<String, String[]> params = context.getParameters();

// 获取请求头（原始）
Map<String, String> headers = context.getHeaders();
```

### 2.3 实际使用示例

#### 示例1：在 Service 中获取当前用户ID

```java
@Service
public class UserService {

    public void updateUser(UserDTO dto) {
        // ❌ 错误：不要自己解析 request
        // HttpServletRequest request = ...;

        // ✅ 正确：使用框架提供的方法
        String userId = MyRequestContextHolder.userId();

        UserDomain domain = userMapstruct.toDomain(dto);
        domain.setUpdatedBy(userId);
        domain.setUpdatedAt(LocalDateTime.now());
        userMapper.updateById(domain);
    }
}
```

#### 示例2：在 Service 中创建新记录时自动填充审计字段

```java
@Service
public class OrderService {

    public void createOrder(OrderDTO dto) {
        String userId = MyRequestContextHolder.userId();

        OrderDomain domain = orderMapstruct.toDomain(dto);
        // ✅ 使用框架提供的 initAudit 方法，自动填充 createdBy, updatedBy, createdAt, updatedAt
        domain.initAudit(userId);

        orderMapper.insert(domain);
    }
}
```

#### 示例3：在 Controller 中获取客户端信息

```java
@RestController
@RequestMapping("/api/order")
public class OrderController {

    @GetMapping("/list")
    public List<OrderDTO> getOrderList() {
        // ✅ 获取客户端版本，用于版本兼容逻辑
        Long version = MyRequestContextHolder.version();

        if (version != null && version >= 200) {
            // 新版本返回更多字段
            return orderService.getOrderListFull();
        }
        return orderService.getOrderListSimple();
    }
}
```

#### 示例4：在 Service 中获取完整上下文

```java
@Service
public class LogService {

    public void saveAccessLog(String action) {
        RequestContext ctx = MyRequestContextHolder.getContext();

        LogDomain log = new LogDomain();
        log.setUserId(ctx.getTokenInfo().getUserId());
        log.setIp(ctx.getIpAddress());
        log.setTraceId(ctx.getTraceId());
        log.setAction(action);
        log.setVersion(ctx.getVersion());
        log.initAudit(MyRequestContextHolder.userId());

        logMapper.insert(log);
    }
}
```

### 2.4 请求头说明

客户端请求时需要携带以下头信息：

| 请求头 | 说明 | 示例 |
|--------|------|------|
| `Token` | JWT认证令牌 | `eyJhbGciOiJIUzI1NiJ9...` |
| `versionCode` | 客户端版本号 | `101`, `200` |
| `deviceId` | 客户端类型 | `Android`, `iOS` |
| `Trace-Id` | 追踪ID（自动生成） | `uuid-xxx-xxx` |
| `X-Real-IP` | 真实IP（网关设置） | `192.168.1.1` |

## 三、统一响应格式

### 3.1 为什么不用手动包装

框架已配置 `ResultResponseHandlerMethodProcessor`，所有 Controller 返回值会自动包装为 `ApiResponse` 格式。

### 3.2 响应格式

```json
{
  "code": 200,
  "message": "OK",
  "data": { /* 实际数据 */ },
  "success": true
}
```

### 3.3 Controller 返回值示例

```java
@RestController
@RequestMapping("/api/user")
public class UserController {

    // ✅ 直接返回 DTO，无需包装
    @GetMapping("/{id}")
    public UserDTO getUser(@PathVariable Long id) {
        return userService.findById(id);
    }

    // ✅ 返回 null 会被正确处理
    @GetMapping("/check")
    public UserDTO checkUser(@RequestParam String name) {
        return userService.findByName(name); // null → data: ""
    }

    // ✅ 返回列表无需包装
    @GetMapping("/list")
    public List<UserDTO> listUsers() {
        return userService.list();
    }

    // ✅ 分页数据直接返回
    @PostMapping("/page")
    public PageData<OrderDTO> getPage(@RequestBody OrderPageDTO pageDTO) {
        return orderService.pageQuery(pageDTO.getPage());
    }
}
```

## 四、异常处理

### 4.1 异常体系

```
BaseRuntimeException (抽象基类)
    ├── BusinessException          # 通用业务异常
    ├── BadRequestException       # 请求参数错误
    ├── DataValidationException   # 数据校验异常
    └── CommonsScopeException     # 框架级异常
```

### 4.2 Token 相关错误码

| 错误码 | 常量 | 说明 |
|--------|------|------|
| 8500 | TOKEN_NOT_FOUND_CODE | Token未找到 |
| 8501 | TOKEN_ERROR_CODE | Token未知错误 |
| 8502 | TOKEN_EXPIRED_CODE | Token已过期 |
| 8503 | TOKEN_SECRET_ERROR_CODE | Token签名错误 |
| 8504 | TOKEN_UN_SUPPORTED_CODE | 不支持的Token格式 |
| 8505 | TOKEN_INVALID_CODE | 无效的Token |

### 4.3 抛出异常示例

```java
@Service
public class UserService {

    public void register(UserDTO dto) {
        // 检查用户名是否存在
        if (userMapper.existsByName(dto.getName())) {
            // ✅ 抛出业务异常，code: 400开头表示业务层错误
            throw new BusinessException(400001, "用户名已存在");
        }

        // 检查邮箱格式
        if (!isValidEmail(dto.getEmail())) {
            // ✅ 参数校验异常
            throw new BadRequestException(400002, "邮箱格式不正确");
        }
    }
}
```

### 4.4 全局异常处理

框架已配置全局异常处理器，抛出异常后自动返回：

```json
{
  "code": 8502,
  "message": "token have expired.",
  "data": "",
  "success": false
}
```

## 五、分页组件

### 5.1 分页参数 PageQuery

```java
@Data
public class UserPageDTO {
    private PageQuery page;  // 嵌入分页参数
}
```

请求示例：
```json
{
  "page": {
    "page": 1,
    "size": 10
  }
}
```

### 5.2 分页返回 PageData

```java
// 创建分页结果
PageData<UserDTO> result = PageData.of(totalCount, page, size, records);

// 或使用 Builder
PageData.<UserDTO>builder()
    .total(100L)
    .page(1)
    .size(10)
    .records(list)
    .build();
```

### 5.3 Service 分页查询示例

```java
@Service
public class UserService {

    public PageData<UserDTO> pageQuery(PageQuery query) {
        // 1. 执行分页查询
        Page<UserDomain> page = new Page<>(query.getPage(), query.getSize());
        LambdaQueryWrapper<UserDomain> wrapper = new LambdaQueryWrapper<>();
        wrapper.eq(UserDomain::isDelFlag, false);
        wrapper.orderByDesc(UserDomain::getCreatedAt);

        Page<UserDomain> resultPage = userMapper.selectPage(page, wrapper);

        // 2. 转换为 DTO
        List<UserDTO> dtoList = resultPage.getRecords().stream()
            .map(userMapstruct::toDTO)
            .collect(Collectors.toList());

        // 3. 返回 PageData
        return PageData.of(
            resultPage.getTotal(),
            query.getPage(),
            query.getSize(),
            dtoList
        );
    }
}
```

### 5.4 Controller 分页接口

```java
@RestController
@RequestMapping("/api/user")
public class UserController {

    @PostMapping("/page")
    public PageData<UserDTO> getUserPage(@RequestBody @Valid UserPageDTO pageDTO) {
        return userService.pageQuery(pageDTO.getPage());
    }
}
```

## 六、数据加解密 (APP接口)

### 6.1 场景说明

APP 调用接口时，请求体和响应体中的 `data` 字段需要进行 AES 加密传输，防止中间人攻击。

### 6.2 启用方式

```java
@SpringBootApplication
@EnableEncrypt  // 添加此注解
public class SeniorPostApplication {
    public static void main(String[] args) {
        SpringApplication.run(SeniorPostApplication.class, args);
    }
}
```

### 6.3 配置

```yaml
wj:
  security:
    key: d86d7bab3d6ac01ad9dc6a897652f2d2  # AES密钥
    debug: false                            # 调试模式（Swagger测试时设为true）
    android-version: 100                    # Android低于此版本不加密
    ios-version: 100                        # iOS低于此版本不加密
```

### 6.4 请求/响应格式

**请求格式：**
```json
{
  "data": "base64加密后的JSON"
}
```

**响应格式：**
```json
{
  "code": 200,
  "message": "OK",
  "data": "base64加密后的响应数据",
  "success": true
}
```

### 6.5 Controller 示例

```java
@RestController
@RequestMapping("/api/user")
public class UserController {

    // ✅ 请求解密 + 响应加密
    @Decrypt
    @Encrypt
    @PostMapping("/login")
    public UserDTO login(@RequestBody LoginDTO loginDTO) {
        return userService.login(loginDTO);
    }

    // ✅ 忽略解密（用于不需要解密但在其他加密范围内的接口）
    @EncryptIgnore
    @GetMapping("/public")
    public String getPublicInfo() {
        return "public info";
    }
}
```

## 七、领域模型基类

### 7.1 Domain 基类：AbstractAuditableDomain

```java
// 继承此基类后自动获得审计字段
public class UserDomain extends AbstractAuditableDomain {
    private Long id;
    private String name;
    // ... 其他业务字段
}
```

**继承的字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| createdAt | LocalDateTime | 创建时间 |
| createdBy | String | 创建人ID |
| updatedAt | LocalDateTime | 更新时间 |
| updatedBy | String | 更新人ID |
| delFlag | boolean | 软删除标记 |

**提供的方法：**

```java
// 初始化审计字段（新增时调用）
user.initAudit(userId);

// 更新审计字段（更新时调用）
user.updateAudit(userId);

// 标记删除（软删除时调用）
user.markDeleted(userId);
```

### 7.2 DTO 基类：AbstractAuditableDTO

```java
// DTO 继承此基类
public class UserDTO extends AbstractAuditableDTO {
    private Long id;
    private String name;
    // ... 其他业务字段
}
```

### 7.3 Service 中使用示例

```java
@Service
public class UserServiceImpl extends ServiceImpl<UserMapper, UserDomain>
    implements UserService {

    @Override
    public void upsert(UserDTO dto) {
        String userId = MyRequestContextHolder.userId();

        if (dto.getId() == null) {
            // 新增
            UserDomain domain = userMapstruct.toDomain(dto);
            domain.initAudit(userId);  // ✅ 初始化审计字段
            save(domain);
        } else {
            // 更新
            UserDomain domain = userMapstruct.toDomain(dto);
            domain.setId(dto.getId());
            domain.updateAudit(userId);  // ✅ 更新审计字段
            updateById(domain);
        }
    }

    @Override
    public void delByIds(List<Long> ids) {
        // ✅ 软删除：设置 delFlag = true
        UserDomain domain = new UserDomain();
        domain.setDelFlag(true);
        domain.updateAudit(MyRequestContextHolder.userId());

        update(domain, new LambdaQueryWrapper<UserDomain>()
            .in(UserDomain::getId, ids));
    }
}
```

        // 存储

        UserDTO cached = (UserDTO) redisTemplate.opsForValue().get("user:" + userId);

## 十一、常见问题

### Q1: 如何获取当前登录用户ID？

```java
String userId = MyRequestContextHolder.userId();
```

### Q2: 如何判断用户是否登录？

```java
TokenInfo tokenInfo = MyRequestContextHolder.getContext().getTokenInfo();
if (tokenInfo != null && StringUtils.isNotBlank(tokenInfo.getUserId())) {
    // 已登录
}
```

### Q3: 如何返回错误响应？

```java
throw new BusinessException(400001, "业务错误信息");
```

### Q4: 如何返回成功但data为null？

```java
return null;  // 自动处理为 data: ""
```

### Q5: 分页接口怎么写？

```java
// Controller
@PostMapping("/page")
public PageData<XxxDTO> page(@RequestBody @Valid XxxPageDTO dto) {
    return xxxService.pageQuery(dto.getPage());
}

// Service
public PageData<XxxDTO> pageQuery(PageQuery query) {
    Page<XxxDomain> page = xxxMapper.selectPage(
        new Page<>(query.getPage(), query.getSize()),
        new LambdaQueryWrapper<XxxDomain>().eq(XxxDomain::isDelFlag, false)
    );
    List<XxxDTO> list = page.getRecords().stream()
        .map(mapstruct::toDTO).collect(Collectors.toList());
    return PageData.of(page.getTotal(), query.getPage(), query.getSize(), list);
}
```

### Q6: APP接口如何启用加密？

1. 添加 `@EnableEncrypt` 注解
2. 配置 `wj.security.key`
3. Controller 方法添加 `@Decrypt`/`@Encrypt` 注解

### Q7: 如何新增一条记录？

```java
// 方式1：通过 Feign Client
userFeignClient.feignAdd(userDTO);

// 方式2：通过 Service
userService.upsert(userDTO);  // id为null时自动新增
```

## 十二、禁止事项

1. **禁止**在 Service/Controller 中自行解析 HttpServletRequest 获取用户信息
2. **禁止**手动包装 Controller 返回值为 ApiResponse
3. **禁止**在 Service 中直接使用 `new Date()` 设置时间，使用 `LocalDateTime.now()`
4. **禁止**硬编码用户ID，使用 `MyRequestContextHolder.userId()`
5. **禁止**重复造轮子，优先使用框架提供的组件
